# Моя библиотека онлайн-уроков

Готовый статический сайт для GitHub Pages. Стартовые HTML-материалы уже находятся в папке `materials`. Новый HTML в этой папке сайт автоматически обнаруживает через **публичное API GitHub** без ручного обновления карточек.

## Быстрый запуск (через браузер)

1. GitHub → **New repository** → название `online-uroki`, видимость **Public**, включить **Add a README file** → Create repository.
2. Распакуйте этот ZIP. В GitHub откройте репозиторий → **Add file → Upload files**. Перетащите содержимое распакованной папки (файл `index.html`, `catalog.json`, папки `materials` и `covers`, файл `.nojekyll`, при желании это README; не сам ZIP). Сохраните **Commit changes**.
3. **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main → /(root) → Save**.
4. Откройте `https://merivcode.github.io/online-uroki/` после публикации (проверяйте адрес в Settings → Pages). Сайт покажет три карточки.
5. Потом для нового урока: откройте на GitHub **materials → Add file → Upload files** → загрузите HTML и Commit changes. Обновите страницу каталога; появится новая карточка, затем нажмите «Скопировать».

Важно: если новый материал добавлен, но GitHub Pages ещё не завершил публикацию, ссылка может временно выдавать 404. Каталог читает список файлов через API GitHub; при временных сбоях или ограничении API показывает запасной список из catalog.json (первые три материала). На локальном компьютере index.html работает как предпросмотр первоначального каталога.

**Публичность:** файлы GitHub Pages доступны всем, кто знает адрес, и могут индексироваться поисковиками. Нельзя помещать имена учеников, личные данные, результаты занятий или другую приватную информацию.

## Метаданные для новых HTML

Каталог определяет название по `<title>`, а класс и предмет — по имени файла. Для точных красивых карточек можно добавить внутрь `<head>`:

```html
<title>Математический детектив — 3 класс</title>
<meta name="lesson-title" content="Математический детектив">
<meta name="lesson-grade" content="3">
<meta name="lesson-subject" content="Математика">
<meta name="lesson-type" content="Игровой урок">
<meta name="lesson-description" content="Работа с составными задачами и схемами">
<meta name="lesson-tags" content="Задачи;Схемы;45 минут">
```

Не нужно вручную менять index.html или catalog.json после добавления новых материалов. Допускаются подпапки внутри `materials`.

## Если репозиторий назван иначе

На GitHub Pages программа автоматически определяет имя владельца и репозитория из адреса сайта. Главная страница будет `https://USERNAME.github.io/REPOSITORY/`.
