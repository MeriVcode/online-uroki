# Моя библиотека онлайн-уроков

Рабочий каталог интерактивных HTML-материалов для индивидуальных онлайн-занятий.

## Адрес сайта

После включения GitHub Pages (ветка `main`, папка `/(root)`):
https://merivcode.github.io/online-uroki/

## Как добавить новый материал

1. В репозитории `online-uroki` нажмите **Add file → Upload files**.
2. Загрузите новый `.html` **в корень репозитория**, рядом с `index.html`.
3. Нажмите **Commit changes**.
4. Откройте или обновите сайт: карточка появится автоматически после синхронизации с GitHub.
5. Найдите материал в каталоге и нажмите **«Скопировать ссылку»**.

**Важно:** HTML-файлы игр и изображения обложек в этой версии находятся в корне репозитория. Папки `materials` и `covers` здесь не требуются.

## Файлы сайта
- `index.html` — главная страница каталога.
- `catalog.json` — сведения о первых трёх материалах.
- `*_2_math.html` — три стартовых тренажёра.
- `*.webp` — обложки.

**Безопасность:** GitHub Pages — публичный сайт. Не размещайте личные данные учеников.
